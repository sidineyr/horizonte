# Contribua com o Horizonte

O Horizonte está aberto e aguardando contribuições da comunidade para melhorar a exploração vocacional educativa. Você pode ajudar mesmo sem programar.

## Onde sua contribuição faz diferença

- Revisão das traduções por falantes de inglês, espanhol, alemão, francês e mandarim.
- Acessibilidade, teclado, leitores de tela e experiência em dispositivos móveis.
- Relatos de erros com passos para reprodução.
- Sugestões educacionais com fontes confiáveis e atenção ao contexto brasileiro.
- Melhorias de documentação, testes e código.

## Como participar

1. Consulte as [issues existentes](https://github.com/sidineyr/horizonte/issues) para evitar duplicações.
2. Abra uma issue com o problema ou proposta. Para mudanças maiores em perguntas, pontuação ou armazenamento, discuta o escopo antes.
3. Para código ou documentação, crie um fork e uma branch com uma alteração bem delimitada.
4. Siga o README para instalar e executar o projeto. Respeite as políticas de segurança das dependências.
5. Envie um pull request explicando o motivo, o comportamento esperado e as verificações realizadas.

Mudanças de código devem passar por pnpm test, pnpm typecheck e pnpm build. Para traduções, mantenha o significado, a intensidade das escalas e os limites da ferramenta; confira os seis idiomas e a preservação das respostas. Alterações apenas documentais podem ser verificadas pela leitura e conferência dos links.

## Cuidados essenciais

- Nunca inclua respostas reais, relatórios pessoais, credenciais ou dados identificáveis. Use exemplos fictícios.
- Não adicione rastreamento, persistência de respostas ou serviços externos de tradução sem discussão e revisão dos avisos.
- Não apresente o questionário ou suas traduções como psicometricamente validados.
- Diferencie fontes consultadas de leituras recomendadas. Cite referências e respeite direitos autorais.
- ENEM, Sisu, Prouni e as formações permanecem no contexto brasileiro.
- Trate participantes e colaboradores com respeito.

As contribuições serão revisadas pelo mantenedor; abrir um pull request não garante sua incorporação. Este convite não concede nem substitui uma licença de software. Verifique os termos disponíveis no repositório antes de redistribuir código ou materiais.
